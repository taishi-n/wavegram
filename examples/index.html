Spectrogram Resolution: FFT Size and Hop Size

Compare STFT analysis settings. Smaller hop-size gives denser time frames, while larger fft-size gives more frequency bins.

Higher time resolution: fft-size 512, hop-size 128

Default analysis: fft-size 1024, hop-size 256

Higher frequency resolution: fft-size 2048, hop-size 512

Lower frame density: fft-size 1024, hop-size 512

<!-- Higher time resolution: more frequent STFT frames. -->
<wavegram-player
  src="https://raw.githubusercontent.com/pdx-cs-sound/wavs/main/voice.wav"
  show-waveform="false"
  spectrogram-height="120"
  fft-size="512"
  hop-size="128"
></wavegram-player>

<!-- Default analysis settings. -->
<wavegram-player

Multichannel WAV

With no channel attribute, each source channel is shown as its own vertical lane. Use channel="mix" to average channels into one mono view, or pass a zero-based channel index to inspect one channel.

Default: all channels

Mix: averaged mono view

Channel 0 only

Channel 1 only

<!-- Default: show every channel as a vertical lane. -->
<wavegram-player src="./stereo-tone.wav"></wavegram-player>

<!-- Mix all channels into one mono waveform and spectrogram. -->
<wavegram-player src="./stereo-tone.wav" channel="mix"></wavegram-player>

<!-- Show only a specific zero-based channel. -->
<wavegram-player src="./stereo-tone.wav" channel="0"></wavegram-player>
<wavegram-player src="./stereo-tone.wav" channel="1"></wavegram-player>

Profile Events

Listen for profiling events and render their details in your own UI.


          

          
<wavegram-player
  id="profile-player"
  src="https://raw.githubusercontent.com/pdx-cs-sound/wavs/main/voice.wav"
  show-controls
  show-time
></wavegram-player>
<pre id="profile-output"></pre>

<script type="module">
  const player = document.querySelector("#profile-player");
  const output = document.querySelector("#profile-output");
  const rows = [];

  function record(name, detail) {
    rows.push({ event: name, ...detail });
    output.textContent = JSON.stringify(rows, null, 2);
    console.table(rows);
  }

  player.addEventListener("profile", (event) => record("profile", event.detail));
  player.addEventListener("playprofile", (event) => record("playprofile", event.detail));
</script>
